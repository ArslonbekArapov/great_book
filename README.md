# arslonbek-tools

A simple Python utility library made by Arslonbek.

## Install
```
pip install arslonbek-tools
```

## Usage
```python
from arslonbek_tools import greet, add, is_even, reverse_text, celsius_to_fahrenheit

print(greet("John"))               # Hello, John! Nice to meet you :)
print(add(3, 5))                   # 8
print(is_even(4))                  # True
print(reverse_text("hello"))       # olleh
print(celsius_to_fahrenheit(100))  # 212.0
```
